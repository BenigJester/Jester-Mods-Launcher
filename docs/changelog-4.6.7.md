# Jester Mods Launcher 4.6.7

Build: 467

Fix:
• Fixed confirmed APKPure downloads opening in a browser instead of using the launcher's download and installation flow.
• Fixed installing older supported game versions: the launcher verifies the package, asks to uninstall the newer game, and continues installation only after removal.
• Fixed installation checks accepting a newer installed build instead of the exact supported build.

Improvements:
• Browser search is now used only when no matching APKPure download link is available.
• Added translated replacement confirmation with backup guidance and cancellation safeguards in all nine non-English languages.

Uninstalling removes local game data. Back up progress before confirming replacement. The launcher does not bypass Android's downgrade restrictions.
